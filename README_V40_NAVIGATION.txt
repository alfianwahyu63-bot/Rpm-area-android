RPM AREA V40 — 11 PILIHAN NAVIGASI UNTUK SETIAP TEMA

CARA UPDATE APK:
1. Backup Lokal & Backup Cloud dari aplikasi lama.
2. Upload ISI ZIP ini ke root repository GitHub Android. Pastikan file tersembunyi .github/workflows/main.yml ikut terunggah.
3. Jika ada workflow lama .github/workflows/build-apk.yml, hapus atau nonaktifkan agar tidak ada dua build bersamaan.
4. GitHub > Actions > Build RPM Area V40 APK > Run workflow.
5. Setelah berhasil, download artifact RPM-Area-V40-APK, ekstrak, instal app-debug.apk.

CARA MENGGUNAKAN:
Setelan > Tema & Gaya > Gaya Navigasi — 11 Pilihan.
Ketuk kartu untuk pratinjau live, kemudian Terapkan untuk Tema Ini.
Setiap tema warna memiliki rekomendasi default berbeda; override disimpan di HP ini.
Reset Rekomendasi Tema untuk kembali ke default warna itu.

PERHATIAN:
APK debug dari build GitHub lain mungkin tidak dapat meng-update aplikasi lama akibat perbedaan tanda tangan.
Jangan uninstall aplikasi lama sebelum backup lokal berhasil. Data web browser tidak otomatis pindah ke APK.
Source tidak mengubah data PLU, target, QTY/NS, Supabase atau SQL.
APK fisik belum dikompilasi atau diuji di HP di lingkungan ChatGPT.
