RPM AREA V41 — TARGET & AKTUAL QTY/NS PER TOKO & BRAND

VERSI ANDROID: 41.0

PENAMBAHAN:
- Menu TARGET > pilih toko, lalu kartu brand menampilkan target QTY, target NS, aktual QTY, aktual NS, persentase ACV QTY, ACV NS, dan POINT.
- Progress bar per QTY dan NS.
- Kartu toko menampilkan target dan aktual beserta persentasenya.
- Buka “Rekap target & aktual per toko / brand” untuk tabel lengkap seluruh toko dan brand.
- Data mengikuti minggu/tanggal yang dipilih (kumulatif).
- Jika target kosong, persentase dan POINT tampil —.

Tidak mengubah data penjualan, list PLU, target, sistem sinkronisasi, ataupun Supabase.
Fitur 11 gaya navigasi V40 tetap dipertahankan.

CARA BUILD APK:
1. Backup data lokal dan cloud lebih dahulu.
2. Upload isi ZIP ke root repository GitHub Rpm-area-android, menimpa source lama.
3. Buka Actions > Build RPM Area V41 APK > Run workflow.
4. Download RPM-Area-V41-APK, ekstrak app-debug.apk.

CATATAN: APK belum dikompilasi/diuji langsung di perangkat. Build debug yang ditandatangani berbeda mungkin tidak dapat menimpa APK lama.
